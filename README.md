# CodeAlpha Data Analytics Internship Project

##  Project Overview
This project was completed as part of the **CodeAlpha Data Analytics Internship**.
It covers 3 tasks using a books dataset scraped from books.toscrape.com.

##  Tasks Completed

### Task 1 — Web Scraping
- Scraped book Title, Price, Rating, Availability & Category
- Used: `requests`, `BeautifulSoup`
- Output: `books_raw_data.csv`

### Task 2 — Exploratory Data Analysis (EDA)
- Data cleaning, type conversion, duplicate removal
- Answered 6 meaningful questions using Pandas
- Output: `books_cleaned_data.csv`

### Task 3 — Data Visualization
- 4 charts: Bar, Count Plot, Scatter, Box Plot
- Used: `Matplotlib`, `Seaborn`


##  Libraries Used
- `requests`, `BeautifulSoup4`
- `pandas`, `numpy`
- `matplotlib`, `seaborn`


##  Dataset
Source: [books.toscrape.com](http://books.toscrape.com)
Categories: Mystery, Science Fiction, Romance, History, Travel
